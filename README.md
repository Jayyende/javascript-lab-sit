## 📌 About the Repository

This repository contains **10 JavaScript Lab experiments** implemented as part of the academic curriculum. The practicals focus on understanding JavaScript fundamentals and applying them to interactive web development.

Each experiment demonstrates important JavaScript concepts through simple, practical implementations using HTML, CSS, and JavaScript. The repository progresses from basic programming concepts to DOM manipulation, form validation, browser storage, and asynchronous data handling.

The objective is to develop practical programming skills and understand how JavaScript makes web pages interactive and dynamic.

## 🎯 Objectives

- Understand JavaScript fundamentals and its role in web development.
- Learn variables, data types, operators, functions, and control structures.
- Implement arrays, objects, and commonly used array methods.
- Understand strings and regular expressions.
- Perform DOM manipulation and handle browser events.
- Develop interactive applications and validate user input.
- Work with localStorage and sessionStorage.
- Retrieve and display JSON data using Fetch API and jQuery.
- Develop problem-solving and practical implementation skills.

### Experiment 3 – Student Grading and Form Validation

- Handling loading and error messages.

**Files:** `index.html`, `style.css`, `script.js`, `data.json`

## ⚙️ Installation and Execution

### Prerequisites

Before running the experiments, make sure you have:

- A computer with a modern web browser.
- Visual Studio Code (recommended).
- Live Server extension in VS Code.
- An internet connection for external CDN resources, such as jQuery in Experiment 10.

### Steps to Run

1. Clone or download this repository.
2. Open the downloaded project folder in Visual Studio Code.
3. Navigate to the experiment folder you want to execute.
4. Open the `index.html` file.
5. Right-click and select **Open with Live Server**.
6. The experiment will open in your default web browser.
7. Interact with the application and check the output.

**Important:** Experiment 10 should be executed using Live Server because it loads data from the local `data.json` file through Fetch API and jQuery.
